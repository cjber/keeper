# Security

keeper deletes data, so a bug that removes something it should have kept is a security issue, as is any way to make it
run a command or act on a path it was not given.

Report a vulnerability through [GitHub private reporting](https://github.com/cjber/keeper/security/advisories/new), not
a public issue. Include the version, the steps to reproduce it and what was affected. You will get a reply within a week.

The latest release is the only supported version.
